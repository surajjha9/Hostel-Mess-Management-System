IMPORTANT TECHNICAL SCOPE
This is a functional FRONT-END DEMONSTRATION PROTOTYPE. It uses HTML, CSS, JavaScript and browser localStorage.
The supplied project report describes Java Spring Boot REST APIs and MySQL as the proposed final architecture, and explicitly says the current prototype screens use sample data and are not yet connected to the backend/database (report pages 19–22).
Do not claim that this ZIP contains a completed Spring Boot backend, MySQL integration, BCrypt authentication, or multi-user live server. Those are planned final-system components, not implemented in this demo.
For an actual deployment, replace localStorage demo data with authenticated REST APIs and MySQL persistence.
